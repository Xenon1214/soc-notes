CIA Triad

The CIA triad is basically the core idea behind cybersecurity. It stands for Confidentiality, Integrity and Availability. Almost any security issue can be understood through one of these three.

Integrity is about making sure data is not changed or tampered with. If a file suddenly changes when it shouldn’t, that’s a problem. For example, malware can modify system files. One simple way to check integrity is hashing — if the hash changes, something changed in the file.

Availability means that systems and data should be accessible when needed. If a website goes down or becomes very slow, availability is affected. A common example is a DDoS attack where the server gets overloaded with traffic.

In reality, most attacks target one or more of these at the same time. For example, ransomware affects both integrity (files are changed) and availability (you can’t access them anymore).
